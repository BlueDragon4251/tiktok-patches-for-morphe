# Native theme surfaces on 46.7.3 and 47.1.3

The connected Android 16 device reproduced empty long-press/share sheets, a
missing profile follower field, invisible notification filters, and white
System notifications cards with Arctic Blue. The original installed baseline
identified BlueIT 1.2.2; its local development source was disabled.

The theme patch now owns the verified TuxNavBar header, System notifications
roots and TuxSheet content. Native lifecycle bodies, real receiver/return
registers, cardinality and mutation contracts remain checked for both pinned
APKs. Native-owned roots avoid the competing dynamic-list pass. Bounded styling
handles late children, neutral text spans, native icon tint and wrapped card
fills while retaining media, functional colors, drawable shape and state.

The generic TUX resolver accepts only a converted value that carries the actual
mapped color. Resource IDs, flags, dimensions and multi-value arrays retain their
native fallback. Theme resolution must also preserve a missing native value:
recognizing a page token does not establish that its Context has a TUX theme.
The resolver now requires a stock color before caching a role or returning an
override. The regression tests use a real resolved theme attribute and separately
exercise the unresolved page token and uncalled converter.

opened a complete native menu, and the follower count/label were visible. No

isolates the failure to the BlueIT patch combination; it does not yet distinguish
its individual hooks. A complete comparison build excluding only Theme engine
has been built successfully but has not yet been installed/tested. The candidate
input is also on the phone as blueit-no-theme47.apk.

Share,

## Installation details

Android killed the original full Manager build with LOW_MEMORY. Heavy patching
therefore runs on the PC; the Manager applies update protection once and signs
with its existing key. The PC input preserves the original version code so this
last pass records the real TikTok version. Reapplying update protection twice is
not a valid reproduction procedure.

No app data were cleared and TikTok was never uninstalled. Exporting the existing
key did not assign a password; temporary exported key copies were removed. The
control update is temporary and the final tested BlueIT build and Manager source
selection must be restored before completing device work. Device screenshots,
process logs, APKs and signing material remain private and outside this repo.
